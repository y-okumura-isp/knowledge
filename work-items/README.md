# Work Items

This directory stores active change requests and implementation notes for this repository.

## Rules

- Put in-progress work items here.
- Move completed items to `work-items/done/`.
- Keep each item focused on a single change or a tightly related set of changes.
- Use this directory for reusable instructions, acceptance criteria, and verification steps.
- Do not use this directory for scratch notes that are only useful during one session.

## Suggested filename format

- `YYYY-MM-DD-short-title.md`
- Example: `2026-06-20-markdown-link-fix.md`

## Suggested structure

```markdown
# Title

## Goal

What should change and why.

## Scope

Files, modules, or behavior in scope.

## Constraints

Rules that must be preserved.

## Acceptance Criteria

- Observable outcomes that define done.

## Verification

- Commands or manual checks to run.
```
